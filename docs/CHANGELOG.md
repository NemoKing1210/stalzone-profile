# Changelog

## 2026-11-15 — первая воспроизводимая версия

- Каркас репозитория: npm workspaces, Nuxt 4 + Nuxt UI, TypeScript strict,
  ESLint, Vitest, Playwright, tsup.
- Общие zod-схемы API и MCP, нормализация названий, ранги, форматирование.
- SQLite-схема: источники, предметы и статы, снаряжение с `qty`, контейнеры,
  сборки, история цен, контент, иконки, журнал событий.
- Импорт легаси-досье, паритет чисел на одной формуле DPS/TTK.
- Иконки: 99 `.webp` из `icons.json` пишутся в `ICONS_DIR` и отдаются по
  `/icons/<sha1>.webp`; оружие, броня, контейнеры и артефакты ссылаются на файл,
  а не на data-URL.
- Нижние слои: репозитории, расчёт артефактов, экспорт старого JSON.
- Сессионная авторизация, rate limit входа по адресу сокета
  (`X-Forwarded-For` — только при `NUXT_TRUST_PROXY=1`), origin-check мутаций.
- REST API `/api/v1`: чтение всех разделов, запись с `dryRun`, журнал и откат.
  Откат удаления контейнера возвращает `extra` и наполнение; откат наполнения
  без контейнера — `409 OWNED_NOT_FOUND`.
- Nuxt UI: девять разделов, поиск, сортировка, карточки, пустые состояния.
- Редактирование: снаряжение, персонаж, контейнеры, сборки, заметки,
  рекомендации, заработок; журнал событий в `/settings`.
- MCP: 21 инструмент, stdio и stateless HTTP `/mcp`, Bearer-токен,
  `dry_run`/`confirm`, лимит 30 записей в минуту, `dossier://schema`.
- Источники: адаптеры EXBO (кэш по коммиту), stalzone.wiki (диапазоны,
  `additionalStats`, TTK 0…15), motifs (219 обликов), profile (ручной снимок),
  scpmodel (TTL 15 минут, `stale` при ошибке); синк из `/settings`, CLI и MCP.
- Деплой: Dockerfile, compose с томом `/data`, healthcheck, Caddy-профиль,
  бэкапы с хранением 14 дней, GitLab CI.
- Документация: README, архитектура, API, MCP, модель данных, миграция,
  runbook; `.env.example`.

### Известные ограничения

- Профиль обновляется вручную: официальный API не отдаёт его сторонним
  приложениям, инвентарь тоже не публикуется.
- 32 из 219 обликов не имеют известной базы в источнике — `base_item_id`
  остаётся пустым, а не угадывается.
- `rebuild_site` в MCP не пересобирает сайт: это делает деплой.
