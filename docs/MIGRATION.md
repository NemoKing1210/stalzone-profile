# Миграция из легаси-проекта

Исходник: `[redacted legacy source]` — статическая
страница внутри Aside-проекта. Данные лежали в `data/my-gear.json` (~795 КБ),
страница грузила весь payload (~1,2 МБ JS), истории изменений не было.

Сиды репозитория (`db/seeds/`) содержат досье, иконки, срез вики, цены и
профиль. Сырая база EXBO (~25 МБ, 9 996 предметов) не коммитится: её
восстанавливает `sync exbo_base` из официального репозитория.

## Паритет чисел

- Все отображаемые DPS/TTK пересчитываются одной формулой из урона и
  скорострельности; сохранённые легаси-числа не подставляются.
- `npm run golden` сверяет 35 единиц оружия, 12 брони, 3 контейнера, 22
  артефакта, 5 сборок, 601 карточку и 495 позиций каталога.
- Результат: **0 mismatches, 0 legacy deltas** — расхождений с исходным досье
  нет. Ранний «аномальный DPS QBU-191» оказался ошибкой сопоставления строк по
  имени без уровня; после ключа `имя+уровень` и округления отображения дельта
  исчезла.

## Сохранённые легаси-особенности

1. **Дубли каталога брони.** В исходном каталоге две пары одинаковых названий:
   «Куртка с бронежилетом» и «Бандитский кожак». Обе позиции сохранены в
   `catalog_entry` с разными `position` — порядок и количество совпадают со
   старой страницей. Дедупликация была бы изменением отображаемых данных.
2. **Три локальных предмета.** В снаряжении есть предметы, которых нет в
   источниках; они созданы как `source_id = local` с точными легаси-значениями:
   - `Обрез Chiappa Triple` (оружие)
   - `КИМ-Х «Аппа… Шлено…»` (броня)
   - `Экзоскелет «Морга»` (броня)
3. **Карточки и каталог — отдельные таблицы.** `item.raw` не мог сохранить
   точные легаси-ключи (`w:`, `a:`, `art:`, `c:`), дубли и позиции каталога.
   Поэтому появились `details_card` и `catalog_entry`; payload читает их первым,
   а старые item-derived карты остаются фолбэком.
4. **Копии снаряжения.** Легаси-массив разворачивал каждую единицу; в `owned`
   одинаковые строки схлопнуты в `qty` (35 оружия и 22 артефакта в досье дают
   меньше строк, но то же число копий).

## Команды

```bash
npm ci
npm run db:migrate
npm run import:legacy
npm run golden
```

Импорт идемпотентен: повторный запуск не плодит строки (агрегация до upsert,
абсолютный `qty`, цены пропускаются по `fetched_at`).

## Откат и сверка

- Экспорт старого формата: `npm run export:json > dossier.json` (или
  `GET /api/v1/admin/export`).
- Каждое изменение через API/MCP пишет `event_log` и откатывается из UI
  (`/settings`) или `rollback_event`.
- Полный сброс: `npm run db:reset && npm run db:migrate && npm run import:legacy`.
